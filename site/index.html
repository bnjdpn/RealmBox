TUTORIELTUTORIAL

De zéro au monde local.

From zero to a local world.

Prévoyez du temps pour le premier lancement : les données serveur sont extraites depuis votre copie locale.

Allow time for the first launch: server data is extracted from your local copy.

  1. 1

    Préparer la machine

    Prepare your computer

    Installez et démarrez Docker Desktop. Utilisez macOS Apple Silicon ou Windows 11 x64. Gardez assez d’espace libre pour le client, les images et les données extraites.

    Install and start Docker Desktop. Use Apple Silicon macOS or Windows 11 x64. Keep enough free space for the client, images and extracted data.

  2. 2

    Préparer votre copie 3.3.5a

    Prepare your 3.3.5a copy

    Vous devez posséder une copie compatible build 12340 avec un dossier Data complet. RealmBox ne fournit ni client propriétaire, ni MPQ, ni données serveur extraites.

    You must own a compatible build 12340 copy with a complete Data folder. RealmBox provides no proprietary client, MPQ or extracted server data.

  3. 3

    Télécharger RealmBox

    Download RealmBox

    Récupérez le DMG macOS arm64 ou l’installateur EXE Windows x64 depuis GitHub Releases. La préversion n’est pas signée : comparez son SHA-256 avec SHA256SUMS.txt.

    Get the macOS arm64 DMG or Windows x64 EXE installer from GitHub Releases. The preview is unsigned: compare its SHA-256 with SHA256SUMS.txt.

    shasum -a 256 RealmBox_*.dmgcertutil -hashfile RealmBox_*.exe SHA256
  4. 4

    Choisir le client et Data

    Choose the client and Data

    Sur Mac, gardez OpenWoW géré. Sur Windows, vous pouvez choisir votre Wow.exe original ou OpenWoW expérimental. Sélectionnez ensuite le dossier qui contient Data.

    On Mac, keep managed OpenWoW. On Windows, you may choose your original Wow.exe or experimental OpenWoW. Then select the folder containing Data.

  5. 5

    Choisir la population

    Choose the population

    Commencez par Équilibré · 50 sur une machine confortable. RealmBox réduira automatiquement cette valeur si la mémoire accordée à Docker est insuffisante.

    Start with Balanced · 50 on a comfortable computer. RealmBox automatically lowers this value when Docker memory is insufficient.

  6. 6

    Installer puis jouer

    Install, then play

    Cliquez sur Installer, laissez chaque composant terminer, puis cliquez sur Jouer. Connectez-vous avec REALMBOX / REALMBOX. L’addon en jeu permet de former une équipe de quatre compagnons.

    Click Install, let every component finish, then click Play. Sign in with REALMBOX / REALMBOX. The in-game addon lets you form a party of four companions.

AIDEHELP

Les réponses utiles, sans jargon.

Useful answers, without jargon.

Docker Desktop n’est pas prêtDocker Desktop is not ready

Ouvrez Docker Desktop et attendez l’état “Engine running”, puis utilisez Réessayer dans RealmBox.

Open Docker Desktop and wait for “Engine running”, then use Try again in RealmBox.

RealmBox refuse mon dossierRealmBox rejects my folder

Choisissez le dossier parent qui contient Data, ou Data directement. La copie doit contenir les archives WotLK et une locale complète.

Choose the parent folder containing Data, or Data itself. The copy must include the WotLK archives and a complete locale.

macOS ou Windows bloque l’ouverturemacOS or Windows blocks the app

La préversion n’est pas signée. Vérifiez d’abord le SHA-256 publié. Sur macOS, utilisez clic droit → Ouvrir. Sur Windows, consultez les détails SmartScreen uniquement si le hash correspond.

The preview is unsigned. Verify the published SHA-256 first. On macOS, use right-click → Open. On Windows, review SmartScreen details only when the hash matches.

Où sont les journaux ?Where are the logs?

Ouvrez Diagnostic dans RealmBox. La vue affiche le chemin local exact et permet de copier un diagnostic filtré.

Open Diagnostics in RealmBox. The view shows the exact local path and lets you copy a filtered diagnostic.
