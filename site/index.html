À la uneFeatured

Tout Azeroth. Sur une seule machine.All of Azeroth. On one machine.

RealmBox est un lanceur libre pour jouer dans un monde 3.3.5a entièrement local. Il prépare les composants, vérifie votre dossier Data, lance votre royaume dans le bon ordre et l’arrête proprement lorsque vous quittez le jeu.

RealmBox is a free-software launcher for playing in a fully local 3.3.5a world. It prepares the components, checks your Data folder, starts your realm in the right order and shuts it down cleanly when you leave the game.

Un monde qui reste chez vousA world that stays with you

Les services de jeu écoutent uniquement en local. Vos données, personnages et sauvegardes ne quittent pas votre ordinateur.

Game services listen locally only. Your data, characters and saves never leave your computer.

Des compagnons pour l’aventureCompanions for the journey

Playerbots peuple le monde et l’addon RealmBox forme une équipe équilibrée qui peut suivre, attaquer, attendre et se regrouper.

Playerbots populates the world, while the RealmBox addon forms a balanced party that can follow, attack, wait and regroup.

Les détails restent au bon endroitDetails stay in the right place

Le parcours joueur montre l’état et la prochaine action. Ports, services et journaux restent dans Diagnostic.

The player flow shows status and the next action. Ports, services and logs stay in Diagnostics.

Ce que RealmBox ne fournit pasWhat RealmBox does not provide

Aucun client WoW, fichier MPQ ou donnée serveur extraite n’est inclus. Vous devez fournir une copie compatible obtenue légalement.

No WoW client, MPQ file or extracted server data is included. You must provide a compatible copy obtained legally.

Installer RealmBoxInstall RealmBox

  1. 1

    Préparez votre machinePrepare your computer

    Installez puis démarrez Docker Desktop. Prévoyez de l’espace pour le client, les images du serveur et les données extraites.

    Install and start Docker Desktop. Allow space for the client, server images and extracted data.

  2. 2

    Trouvez une copie 3.3.5a build 12340Find a 3.3.5a build 12340 copy

    RealmBox attend une copie complète de Wrath of the Lich King 3.3.5a, build 12340, avec les archives common.MPQ, expansion.MPQ, lichking.MPQ et une locale complète.

    RealmBox expects a complete Wrath of the Lich King 3.3.5a build 12340 copy, with common.MPQ, expansion.MPQ, lichking.MPQ and a complete locale.

    ⌕La recherche Google à faireThe Google search to use

    "World of Warcraft" "3.3.5a" "build 12340" client Ouvrir cette recherche sur GoogleOpen this Google search ↗
    • Ajoutez frFR ou enUS si vous cherchez une langue précise.
    • Add frFR or enUS if you need a specific language.
    • Choisissez uniquement une source que vous êtes autorisé à utiliser et dont la provenance est claire.
    • Only choose a source you are authorized to use and whose provenance is clear.
    • Évitez tout “repack”, crack, keygen, exécutable modifié ou archive qui demande de désactiver l’antivirus.
    • Avoid any repack, crack, keygen, modified executable or archive asking you to disable antivirus.
    • Ne vous fiez pas au nom du dossier : RealmBox vérifiera les MPQ puis la build réelle.
    • Do not trust the folder name alone: RealmBox will check the MPQs and then the actual build.
  3. 3

    Téléchargez RealmBox pour votre systèmeDownload RealmBox for your system

    Sur macOS Apple Silicon, prenez le DMG arm64. Sur Windows 11 x64, prenez l’installateur EXE. Comparez ensuite le SHA-256 du fichier avec SHA256SUMS.txt.

    On Apple Silicon macOS, get the arm64 DMG. On Windows 11 x64, get the EXE installer. Then compare the file’s SHA-256 with SHA256SUMS.txt.

    shasum -a 256 RealmBox_*.dmg certutil -hashfile RealmBox_*.exe SHA256
  4. 4

    Indiquez le dossier du jeuSelect the game folder

    Sélectionnez le dossier qui contient Data, ou Data directement. Sur Windows, Wow.exe est recommandé lorsqu’il est présent. Sur Mac, RealmBox utilise OpenWoW pour l’exécution native.

    Select the folder containing Data, or Data itself. On Windows, Wow.exe is recommended when present. On Mac, RealmBox uses OpenWoW for native execution.

  5. 5

    Installez, puis entrez dans le mondeInstall, then enter the world

    Choisissez votre population de compagnons, cliquez sur Installer et laissez chaque étape se terminer. Aux lancements suivants, un clic sur Jouer suffit.

    Choose your companion population, click Install and let every step finish. On later launches, one click on Play is enough.
