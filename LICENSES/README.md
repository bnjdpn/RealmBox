# Licence inventory

The canonical licence texts remain in each source tree pinned by `third-party.lock.toml`. Release packaging must copy the exact texts and copyright notices from those commits into this directory before binary distribution.

Identified so far:

- OpenWoW: GNU AGPL version 3 only.
- AzerothCore Playerbots fork: GNU GPL version 2 only.
- mod-playerbots: GNU GPL version 2 only.
- mod-ollama-chat: GNU AGPL version 3 only.
- Ollama: MIT.

This inventory is not yet a complete redistribution audit.
