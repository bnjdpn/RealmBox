# Politique de sécurité / Security policy

N’ouvrez pas d’issue publique pour une vulnérabilité exploitable, un secret ou une donnée joueur. Utilisez les [avis de sécurité privés GitHub](https://github.com/bnjdpn/RealmBox/security/advisories/new).

Do not open a public issue for an exploitable vulnerability, secret, or player data. Use [GitHub private security advisories](https://github.com/bnjdpn/RealmBox/security/advisories/new).

Incluez la version ou le commit, la plateforme, l’impact, les étapes minimales et une proposition de correction si possible. Ne joignez jamais de MPQ, sauvegarde RealmBox ou journal contenant des chemins personnels.

Include the version or commit, platform, impact, minimal reproduction, and a suggested fix when possible. Never attach MPQs, RealmBox saves, or logs containing personal paths.
