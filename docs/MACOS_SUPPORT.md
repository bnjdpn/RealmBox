# Support macOS

Le développement courant est observé sur macOS 26.6.2 arm64 avec Apple Clang 17 et Xcode complet. Rust, Node et pnpm sont présents. CMake, Ninja, NASM, autoconf, automake et pkg-config ont été installés pour le spike OpenWoW.

Le build x86-64 peut être cross-compilé mais ne sera pas déclaré stable avant un smoke test sur Mac Intel. Aucun certificat Apple n'est disponible dans ce dépôt.
