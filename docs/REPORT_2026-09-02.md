# Rapport factuel — jalon du 2 septembre 2026

> Rapport historique du premier jalon fake-first. L'application a depuis remplacé ce parcours ; consulter `STATUS.md` pour l'état courant.

Décision: **GO pour poursuivre le développement fake-first; NO-GO pour une
release ou une promesse de partie réelle**.

1. **Implémenté.** Workspace Rust/Tauri/React, parcours français guidé,
   persistance SQLite, machine à états, orchestration et client injectables,
   runtime fake, dashboard, quatre compagnons, conversation simulée, arrêt,
   éditeur de configuration atomique, addon à commandes fermées, CI et docs.
2. **Architecture.** `apps/desktop` contient la coquille Tauri et l'UI;
   Les anciens crates de démonstration (`domain`, `storage`, `client`, `orchestrator`) ont depuis été retirés : l’application Tauri est l’unique implémentation produit.
   `runtime` les frontières d'effets; `orchestrator` les parcours; `config`
   l'édition sûre; `test-support` les fakes; `tools/xtask` les tâches; `runtime`
   les manifestes; `addons` l'addon.
3. **Pins upstream.** OpenWoW `2521e1f72eeffd661913be63d1e2b374073c316c`;
   core Playerbots `47960183bb03b83e8943eb2f0f39c16df9710c9d`;
   mod-playerbots `2f7d9f774987d0157c6a0d0cc08c40bec3db3945`;
   mod-ollama-chat `a9d14b0b8955be136e657ac168dd255f5281a535`;
   Ollama `e5e437711540eb4becb393c2847fed6cae6e5cd5`.
4. **Licences.** AGPL-3.0-only pour RealmBox, OpenWoW et mod-ollama-chat;
   GPL-2.0-only pour le fork et mod-playerbots; MIT pour Ollama. Les textes
   upstream inspectés sont dans `LICENSES/`; la redistribution transitive reste
   à auditer.
5. **OpenWoW macOS arm64.** Configuration et build complets réussis. Binaire
   Mach-O arm64 de 55 Mio, ad hoc, SHA-256
   `b5c1c777263c831f3b42fb683d0cbf783c6c3bcf45fde08ea97a1ca50e380cfe`.
6. **OpenWoW Windows.** Non exécuté; workflow `windows-2025` créé, donc résultat
   inconnu.
7. **OpenWoW macOS x86-64.** Non exécuté; workflow `macos-15-intel` créé, donc
   résultat inconnu.
8. **AzerothCore macOS.** Build complet réussi après deux diagnostics. MariaDB
   Connector/C 3.4.9 est incompatible avec les API MySQL 8 attendues. MySQL
   Client 26.7 corrige ce point; il faut aussi épingler GNU Readline plutôt que
   le faux `libreadline` du SDK macOS. `authserver` et `worldserver` sont des
   Mach-O arm64; SHA-256 de `worldserver`:
   `51c6137ddb027b663418c60c59b19149f68fb796fc35ffb9ee3b0f0c5682e7ae`.
9. **AzerothCore Windows.** Non exécuté; workflow créé, résultat inconnu.
10. **Playerbots.** Module détecté et compilé dans `libmodules.a` lors du premier
    build macOS; aucun comportement en jeu testé.
11. **mod-ollama-chat.** Module détecté et compilé dans `libmodules.a`; les clés
    de configuration sont vérifiées dans la source épinglée, mais aucune requête
    Ollama ni réponse en jeu n'est testée.
12. **Patchs.** Aucun patch upstream. RealmBox ne contient que ses intégrations,
    manifestes et le correctif de chemins de dépendances dans son workflow CI.
13. **Commandes principales exécutées.** `pnpm install`, `pnpm verify`,
    `cargo xtask doctor`, `pnpm --dir apps/desktop tauri build --bundles app`,
    `cmake --preset ci-macos-arm64`, `cmake --build --preset ci-macos-arm64
    --target openwow-client --parallel 8`, puis configuration/build CMake du core
    avec modules et chemins MySQL/Readline explicites.
14. **Réussites.** Typecheck, lint, build Vite, Clippy sans avertissement,
    formatage, 2 tests UI et 15 tests Rust; bundle Tauri et OpenWoW arm64;
    compilation statique des deux modules serveur.
15. **Échecs.** `cargo xtask doctor` a d'abord échoué faute d'alias, corrigé et
    retesté. Deux builds serveur ont révélé les incompatibilités Connector/C
    puis Readline SDK; les deux sont corrigées et le troisième build passe.
    Aucun échec n'est masqué.
16. **Artefacts.** `target/release/bundle/macos/RealmBox.app` et binaire temporaire
    OpenWoW arm64. Le bundle RealmBox est ad hoc, SHA-256 de son exécutable
    `4bc4e146bb4f945efb8c9364fbab1b911900200b83b5c513415404992244a5be`.
17. **Preuves fake.** Onboarding, sélection de données de démonstration,
    préparation progressive, reprise, Jouer, groupe équilibré, conversation,
    arrêt, erreurs de lancement et refus d'arrêt.
18. **Preuves runtime réel.** Lancement du bundle Tauri et migration SQLite;
    builds natifs complets OpenWoW, authserver, worldserver et outils. Aucun
    monde réel, modèle Ollama ou service de base n'a été lancé.
19. **Données utilisateur requises.** Validation et lecture OpenWoW, import du
    monde, compte/personnage, connexion, bots visibles, addon en jeu et session
    prolongée.
20. **Limites.** Runtimes de base et Ollama non gérés, CanIRun non résolu,
    catalogue modèle volontairement vide, backup/restore réels non implémentés,
    plateformes secondaires et packaging de distribution non prouvés.
21. **Risques juridiques.** Compatibilité des licences copyleft et notices des
    dépendances transitives à faire revoir; aucun contenu propriétaire ne doit
    entrer dans le dépôt ni dans les artefacts.
22. **Risque technique principal.** Le client OpenWoW est expérimental et son
    build ne prouve pas qu'il lit les données 3.3.5a utilisateur puis entre dans
    un monde Playerbots de façon stable.
23. **Prochaine étape prioritaire unique.** Construire un harness macOS arm64
    reproductible qui installe une base locale, lance le serveur compilé avec
    les deux modules, puis prouve sa santé sans utiliser de données de jeu.

Le présent rapport ne vaut ni validation Windows/Intel ni readiness de release.
