# Compatibilité

La cible de données/protocole déclarée par OpenWoW 0.1.2 au commit épinglé est 3.3.5a build 12340. Cette déclaration source ne remplace pas un test avec les données de l'utilisateur. Les locales reconnues initialement par le validateur RealmBox sont `frFR`, `enUS`, `deDE`, `esES` et `ruRU`; la compatibilité complète de chacune reste à tester.

Le mode client historique est une abstraction Windows avancée désactivée. Wine, Whisky, CrossOver et les machines virtuelles sont hors périmètre.
