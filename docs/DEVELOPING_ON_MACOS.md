# Développer sur macOS

`pnpm dev:fake` lance le frontend sans données ni services. `pnpm dev` lance Tauri avec SQLite dans `~/Library/Application Support/org.realmbox.desktop/` selon la résolution de chemin Tauri. Les logs et runtimes réels ne sont pas encore installés.

Ne placez jamais de données de jeu, dumps SQL utilisateur, modèles ou secrets dans le dépôt.
