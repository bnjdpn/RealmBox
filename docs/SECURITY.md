# Sécurité

Tous les ports publiés écoutent uniquement sur loopback. RealmBox ne demande pas root/admin, ne crée pas de règle firewall et ne désactive aucune protection système. L'archive OpenWoW est vérifiée par SHA-256 et signature avant exécution ; les sources serveur sont vérifiées au commit exact avant build.

Le mot de passe MySQL est aléatoire, écrit avec le mode `0600` et transmis aux conteneurs par environnement Compose, jamais comme argument de processus. Le compte joueur `REALMBOX / REALMBOX` est un identifiant local non privilégié explicitement affiché, pas un secret. Le client lancé est suivi par son PID en mémoire ; la persistance robuste de l'identité du processus après crash du lanceur reste à faire. Aucun arrêt par nom n'est utilisé.

Le guide local ne transmet pas le terme saisi au shell : il valide le texte puis fournit son hexadécimal UTF-8 dans une variable d’environnement à l’une de deux requêtes constantes. Celles-ci sont bornées, assorties d’un délai MySQL de 2 secondes et exécutées dans une transaction en lecture seule. Les processus hôtes ont des limites distinctes : 10 secondes pour l’inspection et la recherche, 125 secondes pour démarrer la base, 15 secondes pour tenter son arrêt. Le dépassement termine uniquement le groupe de processus ou Job Object détenu par RealmBox ; il ne prouve pas l’arrêt du conteneur si Docker est inaccessible. Les captures temporaires privées sont supprimées et leur lecture limitée à 64 KiB. Le guide réutilise encore le compte root local du runtime ; un compte dédié `SELECT` demandera une migration versionnée et la sauvegarde obligatoire qui la précède. Aucun résultat ou secret du guide n’entre dans le diagnostic partageable.

Les profils solo enregistrent uniquement onze valeurs de configuration contrôlées et leurs empreintes dans des fichiers privés, hors du runtime remplaçable. Journaux et instantanés sont synchronisés, relus, puis publiés atomiquement sans écrasement ; une corruption finale bloque l’action. Un verrou de processus empêche deux applications RealmBox d’intercaler lancement, modification de configuration et arrêt temporaire de la base.

Signaler les vulnérabilités sans publier de secret ou de donnée propriétaire.
