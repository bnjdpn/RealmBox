# ADR 0001 — Licence du dépôt

Statut : accepté provisoirement, revue juridique requise.

RealmBox utilise AGPL-3.0-only pour rester compatible avec l'obligation la plus forte identifiée dans OpenWoW et mod-ollama-chat. Cette décision ne résout pas à elle seule la combinaison avec des composants GPL-2.0-only ; les processus séparés, liens et distributions doivent être revus avant publication.
