# Vision produit

RealmBox n'est pas un panneau d'administration. Après une préparation initiale guidée, le parcours nominal doit se réduire à ouvrir l'application, cliquer sur Jouer, entrer dans le monde local, retrouver des compagnons et fermer le jeu. Les détails de base, ports, serveur, modèle et processus restent dans les diagnostics avancés.

La mesure de réussite est le parcours joueur complet, pas le démarrage isolé d'un processus serveur.
