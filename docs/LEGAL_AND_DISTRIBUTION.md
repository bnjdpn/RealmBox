# Aspects juridiques et distribution

RealmBox ne distribue aucun contenu propriétaire. Les utilisateurs doivent fournir leurs propres données compatibles. OpenWoW et mod-ollama-chat sont AGPLv3 ; le fork serveur, mod-playerbots et l'image MySQL déclarent GPLv2 ; Ollama fournit une licence MIT. Les modèles facultatifs ne sont pas inclus dans RealmBox : l’écran affiche leur licence avant que le joueur confirme le téléchargement local. Qwen 3 est sous Apache-2.0, Gemma 3 sous les Gemma Terms of Use et Llama 3.2 sous la Llama 3.2 Community License. Les dépendances transitives et la composition exacte des images Docker exigent encore un inventaire complet.

La licence AGPL-3.0-only de RealmBox est un choix conservateur, pas une conclusion juridique sur la compatibilité de chaque combinaison. Une revue juridique est requise avant distribution binaire, notamment pour la combinaison AGPLv3/GPLv2-only et les obligations de source correspondante.

Cette revue est suivie dans l’issue GitHub `Obtenir la revue juridique de la distribution binaire combinée`, jalon `0.4 — Public beta`. Sa clôture exige un avis compétent et l’inventaire des notices/sources correspondantes ; un test vert, un SBOM ou le présent document ne peuvent pas la remplacer. Les workflows continuent donc de ne produire qu’une prerelease brouillon tant que cette porte, la signature et la qualification Windows restent ouvertes.
