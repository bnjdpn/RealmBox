# RealmBox 0.5.0 — préversion / preview

## Nouveautés

- Assistant d’installation FR/EN en trois étapes, contrôles de préparation et raccourcis sur l’accueil.
- Trois profils solo inspectables et réversibles, avec snapshots privés et reprise après interruption.
- Recherche locale explicite de quêtes et d’objets, sans IA ni service externe.
- Préréglages d’escouade, compagnon principal observé, portée groupe/cible et aperçu des commandes dans l’addon.
- Protection contre le pilotage simultané du même royaume par deux instances.
- Correctif serveur de dialogue local : coupe-circuit partagé et reprise bornée après échecs. Son inclusion dans les binaires dépend de la reconstruction des images serveur de cette version.

## Validation et limites

Préversion en préparation, conservée en brouillon. Les installateurs et leurs sommes SHA-256 seront ajoutés après construction et vérification ; leur présence ne constitue pas une qualification en jeu.

Les validations locales couvrent 52 tests React, 28 tests de scripts, 141 tests desktop Rust et 5 tests xtask, ainsi que le typage, le lint et les builds web. Un échec intermittent du test de libération du verrou d’instance a été observé pendant la préparation ; ne pas le confondre avec une preuve de défaillance du royaume réel.

Le parcours complet de cette version reste à requalifier sur macOS Apple Silicon et Windows x64. Windows reste expérimental. Les artefacts ne disposent pas d’une signature de distribution ni d’une notarisation.

La version Cargo passe à 0.5.0 pour déclencher la sauvegarde obligatoire avant migration. Aucune donnée joueur, donnée de jeu propriétaire, archive client ou modèle n’est inclus. Une copie compatible de WoW build 12340 appartenant au joueur est requise.

## English summary

This preview adds a guided bilingual setup, reversible solo profiles, explicit local quest/item lookup, companion squad presets and a single-instance runtime guard. The server dialogue circuit breaker requires freshly rebuilt server images.

This is a draft, not a public or gameplay-qualified release. Installers and checksums are pending build verification. Full macOS and Windows gameplay paths still require fresh qualification; Windows remains experimental. Distribution signing and notarization are not provided. No proprietary game data or player data is included.
